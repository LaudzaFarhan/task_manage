# task_manage

A polished, responsive task manager web app — no backend, no build step. Just open `index.html` in a browser.

## Features

- Add, edit, delete, and complete tasks
- Filter by status and sort your list
- Progress summary at a glance
- Import/export tasks as JSON

## Run it

Open `index.html` in any modern browser, or serve the folder with any static server:

```sh
npx serve .
```

## Deploy

Any static host works (GitHub Pages, Netlify, Vercel, …). For GitHub Pages: repo Settings → Pages → Deploy from branch → `main` → `/ (root)`.
